This is a tiny synthetic-data sanity run with disjoint provider voice IDs between training and evaluation. The poor held-out student result (18.23% frame accuracy; missed switch) is retained deliberately: it exposes failed transfer that the earlier same-voice split hid. A separate frozen-checkpoint voice/text factorial found a material 50-point seen-versus-unseen profile gap, the largest tested factor, but the male-seen/female-unseen confound and 71.43% familiar-audio ceiling show that profile diversity is not a sufficient sole fix. Previous-anchor hold removes the old future-information leak, and schema 5 proves both its manifest generation and stored dense tensors; its 250 ms quantization and the slow teacher trajectory remain method limitations. This process's six-thread offline replay has median RTF 0.0058 (range 0.0053–0.0078), but equivalent process reruns have varied materially, so it is not presented as a stable speed factor or online SLO. Preserving actual call phase changes group posteriors by mean/max L1 0.1864/0.4707 relative to the invalid reconstructed schedule, but the corrected policy still misses the switch. Do not interpret these synthetic renderer results, teacher agreement, label accuracy, or a single switch outcome as population estimates.
