# Recorded run

These artifacts were produced on CPU from the commands in the repository README. Audio, cached teacher posteriors, and the student checkpoint are intentionally excluded.

- `summary.json` is the comparison-friendly result required by the assignment.
- `teacher_metrics.json`, `train_metrics.json`, and `eval_metrics.json` retain stage-level evidence. Training and evaluation share schema-2 content-derived run ID `lidrun-ee92beb2…ece4a5`, which binds an immutable pre-preload snapshot of all 94 content-addressed audio files, recipe-bound manifest, schema-4 target index, teacher, timing/model/source configuration and settings, then adds the final model/checkpoint and exact training evidence. Three live equality checks passed before preload, optimization, and publication. Training records 1,600 requested/successful/post-update-checked steps with finite model and optimizer state; evaluation validates the complete identity, all 94 target files, all 41,195 dense raw/soft reconstructions, and the 2,394-frame switch availability ledger before scoring, and records that four provisional tail frames are withheld. It also retains all 50 actual switch-replay call records: 794 stable and 773 delay-aligned outputs form 49 policy groups, with the first group available at 0.335 s rather than the old reconstruction's 0.375 s.
- `switch_plot.png` plots the offline teacher against the deployed chunk-EMA student trace.
- `tests.txt` records the final 42-test run, including corpus recipe/cache/publication checks, causality/alignment boundaries, fake-clock emission scheduling, causal target-expansion and padded-edge availability checks, forged dense/soft target-lineage rejection, invalid training settings, injected post-update corruption, launch-snapshot race rejection, and run-identity mismatch rejection.

This is a tiny synthetic-data sanity run with disjoint provider voice IDs between training and evaluation. The poor held-out student result (18.23% frame accuracy; missed switch) is retained deliberately: it exposes failed transfer that the earlier same-voice split hid. A separate frozen-checkpoint voice/text factorial found a material 50-point seen-versus-unseen profile gap, the largest tested factor, but the male-seen/female-unseen confound and 71.43% familiar-audio ceiling show that profile diversity is not a sufficient sole fix. Previous-anchor hold removes the old future-information leak, and schema 4 now proves the stored dense tensors follow that hold; its 250 ms quantization and the slow teacher trajectory remain method limitations. Stable stateful replay has a six-thread median offline compute RTF of 0.0883; whole-waveform feature extraction means this is not an online SLO. Preserving actual call phase changes group posteriors by mean/max L1 0.1864/0.4707 relative to the invalid reconstructed schedule, but the corrected policy still misses the switch. Do not interpret these synthetic renderer results, teacher agreement, label accuracy, or a single switch outcome as population estimates.
