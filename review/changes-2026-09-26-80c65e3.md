4. **Why is zero-padding a short clip different from batch padding?** Batch padding is ignored only when the true length reaches every length-aware component. These experiments first extend the logical request and then declare the extension valid, so teacher pooling and student frame averaging consume synthetic silence as evidence.
5. **Does longest-first external-teacher scoring change which examples are evaluated?** No. The prefix set is identical, eligibility is unchanged, and predictions are assigned by original index; the change only alters allocation order. A completed report is still required before any selection conclusion.
