### [METHOD] `experiments/checkpoint-external-validation/run.py:825-878,947-990` — the confidence interval breaks utterance clusters and ignores adaptive checkpoint selection

Each FLEURS utterance contributes correlated 1 s, 2 s, and full-clip decisions. `paired_bootstrap_gain()` independently samples each language/prefix block, so the same clip is represented by unrelated draws in its three repeated views. A deterministic stress test with 7 languages × 100 clips, per-clip paired values repeated across all three prefixes, and 53 `+1` / 47 `-1` values has a 6-point estimate. The current routine reports a 95% interval of **[1.7143, 10.3810] pp**, excluding zero; an utterance-clustered resample preserving the three views reports **[-1.4286, 13.4286] pp**.

The interval is then computed only after the same FLEURS metrics have screened and selected a challenger from up to five states. It is therefore an ordinary fixed-comparison interval after adaptive model selection, not confirmation of the selection rule.

Resample utterance IDs within language and carry every eligible prefix view together. For valid selection-aware uncertainty, rerun the complete eligibility/selection operation inside each replicate and report the selected rule's distribution, or reserve an untouched confirmation split; if neither is possible, treat the interval as descriptive and adjust for the candidate comparisons.

## Interview questions

1. **Why are matching start/end source hashes insufficient?** Python may already have imported source A before both hashes observe on-disk B. The main fix stages bytes before any project import and executes a fresh child whose module origins are all inside that stage.
2. **Why must bootstrap resampling keep prefixes together?** The 1 s, 2 s, and full predictions are repeated measurements of the same utterance, not independent clips. Resampling each view independently inflates the effective sample size and can turn an interval crossing zero into one that excludes it.
3. **Why can an external gain still be non-promotable?** A relative win over a collapsed baseline can preserve zero recall for one class, unusable switch behavior, or excessive churn. Absolute task floors must be satisfied before relative ranking matters.
4. **What makes a cached external manifest semantically trustworthy?** Its records must be rederived from pinned source rows and deterministic selection—not merely self-hashed—and config/language, IDs, paths, uniqueness, source hashes, and audio hashes must all agree.
5. **Why does the current checkpoint fail under source schema 3?** Schema 3 adds a materially different executed-source identity. Accepting schema 2 would falsely claim the new pre-import guarantee for an artifact that never recorded it, so retraining/republication (or an explicit historical archive) is required.
6. **What does the KD-bias audit establish and not establish?** It establishes that balanced clip counts yield strongly imbalanced soft supervision and that four Edge-English targets are wrong. It does not explain Marathi collapse or prove that hybrid hard/soft training will generalize; that requires the proposed controlled factorial.
