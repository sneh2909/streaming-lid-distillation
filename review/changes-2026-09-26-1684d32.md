### [BUG] `src/streaming_lid/data.py:498-595` — “Native-space evidence” accepts impossible teacher indices, labels, and probabilities

The validator checks only that `full_top1_indices` are nonnegative and that a
reported full-space maximum is at least the largest reconstructed selected
probability. When an index is outside the seven selected indices, it never
checks the upper bound, the pinned index-to-label mapping, or any relationship
between the claimed label and index.

In a temporary copy of the valid strict-cache fixture, I changed the one native
top-1 record to index `999`, label `not-a-real-teacher-label`, and probability
`0.9`, then updated the target-file/file-set hashes. `TeacherTargetCache.load`
accepted the file. A second 70-clip fixture was accepted with native top-1
probability `7e-7`; any normalized 107-class distribution must have maximum at
least `1/107 = 0.00934579`. These are internal-consistency failures, not a claim
that an unsigned local self-hash can provide adversarial authenticity.

The published `teacher_full_top1_counts`, selected retained mass, and native
teacher diagnosis can therefore be false while the cache says validation
passed. Retain the full 107-way vector (or exact log probabilities) and derive
all summaries, or at minimum bind the complete pinned label map, require
`0 <= index < 107`, enforce exact index/label equality and the `1/107` lower
bound, and add self-rehashed mutation tests for both supported and unsupported
native winners.

### [METHOD] `src/streaming_lid/config.py:81-86`; `src/streaming_lid/data.py:921-964` — The target “quality floor” can pass supervision with negligible native support

`quality_floor.passed` depends only on exactly ten monolingual clips per class
and at least eight conditional seven-way argmaxes matching the manifest label.
It does not gate selected-language retained mass, whether the native top-1 is a
supported language, or even the manifest-label posterior. This preserves the
same failure mode as seven-way renormalization: ranking first inside a tiny
selected subset is called correct even when the native teacher rejects the
subset.

A worked 70-clip fixture with ten clips per language, correct selected argmax
on all 70, and `in_set_mass = 1e-6` returned:

```text
quality_passed True
failed_languages []
min_retained_mass 9.99999997e-07
```

The current artifact happens to fail English (6/10), and it honestly exposes
English's 51.28% clip-mean retained mass and only 1/10 native-English winners.
That useful failure does not make a future `passed=true` a target-quality
statement. Either call this a selected-seven-way rank diagnostic, or add
predeclared per-language retained-mass, native-label correctness, and
manifest-posterior floors. Keep each dimension visible rather than collapsing
them into an unqualified pass flag.

### [DEFEND] `src/streaming_lid/data.py:676-950` — “Frame loss weight share” is a full-corpus surrogate, not the realized optimizer exposure

The audit pools every valid ramp-weighted frame once and divides by the corpus
total. Training instead normalizes the loss independently inside each
seven-clip batch, shuffles with seed 7, drops one of 71 examples per epoch, and
stops after 1,600 batches. Example influence is therefore
`weight_i / sum(batch weights)`, not `weight_i / sum(corpus weights)`.

Replaying the exact sampler schedule produced 153--160 appearances per clip.
The audit reports a 2.7349% mixed-source share; realized normalized minibatch
exposure is 2.4495%. The maximum source-share difference is 0.2854 percentage
points and the maximum `T=2` class-mass difference is 0.0948 points. These are
small here and do not change the conclusion that English target mass is badly
underrepresented. For a live defense, name the current values
`full_corpus_frame_ramp_share`; if claiming actual optimization pressure,
record batch IDs/denominators and compute exposure from the executed schedule.

## Interview questions

1. **How can a teacher be “correct” after seven-way selection but wrong in its
   native output?** Renormalization preserves ordering only among the selected
   seven classes. An unsupported class can dominate the 107-way posterior while
   the manifest class still wins the tiny retained subset.
2. **Why is `1/107` a necessary lower bound for native top-1 probability?** In
   any normalized 107-class vector, at least one component is no smaller than
   the mean. A reported maximum below `1/107` is mathematically impossible.
3. **What exactly does the aggregate target-mass audit measure?** It is the
   class distribution after weighting every causally valid target frame by the
   early ramp once across the corpus. It is not the realized sequence of
   independently normalized minibatch gradients.
4. **Does a failed diagnostic floor need to abort training?** Not necessarily
   for a deliberately retained failure baseline, but the failure must remain
   visible and cannot support a claim of balanced supervision or a promotable
   model. A production gate should be separate and predeclared.
5. **Why did 59 passing tests not make the committed release runnable?** The
   fixture tests build caches from current source. They did not assert that the
   checked-in teacher, checkpoint, train/eval/summary, docs, and transcript all
   came from the same final source/configuration generation.
